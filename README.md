# Eagle City brand assets

Public-host bucket for brand images used by Eagle City systems (email signatures, public pages, etc).

Files here are deliberately committed to a public repo so they can be referenced via stable `raw.githubusercontent.com` URLs.

## Files

| File | Use |
|---|---|
| `tyler-headshot.png` | Tyler's headshot, 240px square. Used in the email signature. |
| `eagle-city-logo.png` | Cactus logo, transparent background, 240px. Used in the email signature and other branded surfaces. |

## Don't commit secrets here.

This repo is public. Only branding artifacts intended for public consumption belong in it.
